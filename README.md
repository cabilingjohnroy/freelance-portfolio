# John Roy Cabiling: Freelance Web Developer Portfolio

Portfolio site for my freelance website business for small businesses in Metro Manila.

**Live:** https://johnroy-cabiling.netlify.app

## What's on the page
- Sample work: [Tala Coffee](https://cafe-website-q2ij.netlify.app) and [Kanto Cuts](https://barbershop-website-gkij.netlify.app)
- Starter Business Website package (₱7,500) with inclusions and exclusions
- How the process works
- About and contact

## Tech
HTML5 and CSS3 only. No frameworks, no build step. Hosted on Netlify (free plan).

## Run locally
Open the folder in VS Code → right-click `index.html` → **Open with Live Server**.

## Updating
- Add a new project: copy one `<article class="work-item">` block in `index.html`.
- Change the price or inclusions: the `.ticket` section in `index.html`.
- Colors and font: `css/style.css` → `:root`.
